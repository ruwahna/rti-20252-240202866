# [EXAMPLE] Usability SIGNAL vs New Sakpole — Penelitian Komparasi Usability & UX

**Judul:** Analisis Komparatif Usability dan User Experience pada Layanan Pajak Kendaraan Digital: SIGNAL vs New Sakpole

**Target publikasi:** Sinta 5 (Technology and Informatics Insight Journal - TIIJ)

## Ringkasan

Penelitian ini membandingkan tingkat kemudahan penggunaan (*usability*) dan pengalaman pengguna (*user experience*) antara dua aplikasi pembayaran pajak kendaraan bermotor di Indonesia, yaitu SIGNAL (Samsat Digital Nasional) dan New Sakpole (aplikasi regional Jawa Tengah). Evaluasi dilakukan secara kuantitatif berbasis pengumpulan kuesioner dari 194 responden valid dengan instrumen *System Usability Scale* (SUS) dan *User Experience Questionnaire* (UEQ), didukung oleh uji beda statistik *Independent T-Test*.
